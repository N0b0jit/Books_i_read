# Books I Read

A personal digital library (~2500 titles, ~29 GB) of Bengali literature,
Hindu scriptures, Islamic texts, astrology, and English-language textbook
PDFs (Psychology, SOC Analyst, etc.).

> **Note:** PDFs are tracked with **Git LFS** (see `.gitattributes`).
> To add/clone large PDFs you must have `git-lfs` installed:
> ```
> git lfs install
> ```

## Contents

- `books_index.csv` — full catalog (path, size, ext, mtime) of every file.
- `drive-download-20250116T171806Z-001/` — Bengali literature by author.
- `hindue#/` — Hindu scriptures (Vedas, Upanishad, Ramayana, Puranas).
- `ইসলামিক বই ভান্ডার-*/` — Islamic books (Quran, tafsir, history).
- `জোতিষ বিদ্যা/` — Bengali astrology.
- `ABNORMAL|DEVELOPMENTAL|I-O PSYCHOLOGY/` — academic psychology.
- `PSYCHOLOGICAL ASSESSMENT/` — assessment instruments.
- `PDF Book & Video Class/` — mixed general reads + video classes.
